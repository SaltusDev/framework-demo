# Project — Saltus Framework Demo

---

## Tagline
A modern, rebrandable demo plugin for the Saltus Framework.

---

## Purpose
This plugin demonstrates how to build WordPress plugins using the Saltus Framework. It registers custom post types (`book`, `movie`), taxonomies (`genre`, `writer`, `country`), admin columns, filters, meta boxes, settings pages, assets, and translations via Saltus model configuration files.

Its marquee feature is the **Rebrand This Demo** UI — a generator that creates a fully customized, installable copy of the plugin with a new name, slug, namespace, author identity, and code prefix. This lets developers bootstrap a production plugin from a working, tested foundation in minutes.
